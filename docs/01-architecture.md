# 01. Архитектура системы

## 1. Назначение

Проект — учебная SoC с собственным 16-битным процессорным ядром. Ядро выполняет программы из отдельной памяти команд, работает с памятью данных, видеопамятью и внешней MMIO-шиной. Управление построено на многотактном автомате Мура; конвейер и кэш отсутствуют.

Основная схема: [PNG-превью](../report/rtl-schema.png) · [drawio](../report/rtl-schema.drawio).

## 2. Ключевые параметры

| Параметр | Значение |
|---|---:|
| Разрядность данных | 16 бит |
| Разрядность команды | 32 бита |
| КОП | 5 бит |
| Регистров общего назначения | 8 × 16 бит, `R0 = 0` |
| `PC` | 10 бит |
| Память команд | 1024 × 32, отдельное адресное пространство |
| Память данных | 1024 × 16 |
| Адрес данных | 16 бит, словная адресация |
| Видеопамять | 8 × 16, младшие 8 бит — строка 8×8 |
| MMIO | 256 адресов, `0xF000–0xF0FF` |
| Сброс | синхронный, активный высокий |
| Тактирование | один `clk`, без асинхронных защёлок |

## 3. Иерархия модулей

```text
soc_top
├── CPU_Core
│   ├── Control_Unit
│   ├── Program_Counter
│   ├── Register_File
│   └── ALU
└── Memory_Top
    ├── Instruction_ROM
    ├── Data_RAM
    └── Video_Memory
```

`Memory_Top` также формирует внешнюю MMIO-шину:

- `mmio_addr[7:0]`;
- `mmio_we`;
- `mmio_wdata[15:0]`;
- `mmio_rdata[15:0]` — вход от внешних устройств.

## 4. Блоки

| Блок | Ответственность |
|---|---|
| `Program_Counter` | хранит `PC`, поддерживает `reset`, `load`, `inc` |
| `Instruction_ROM` | синхронная память команд 1024 × 32 |
| `CPU_Core` | `IR`, тракт данных, управление, регистровый файл, АЛУ, флаги, регистр адреса |
| `Control_Unit` | FSM Мура, управляющие сигналы, `halt` |
| `Register_File` | 8 × 16, два чтения, одна запись, `R0 = 0` |
| `ALU` | 16-битные арифметические и логические операции, `Z/C` |
| `Memory_Top` | ROM, RAM, видеопамять, декодер адреса, MUX чтения, MMIO-шина |
| `soc_top` | соединение CPU, памяти и внешних портов |

## 5. Тракт данных

- `PC` подаёт адрес в `Instruction_ROM`.
- Считанная команда записывается в `IR`.
- Из `IR` выбираются поля:
  - `opcode = IR[31:27]`;
  - `rd = IR[26:24]`;
  - `rs1 = IR[23:21]`;
  - `rs2 = IR[20:18]`;
  - `imm16 = IR[15:0]`.
- `Register_File` выдаёт `rs1_data` и `rs2_data`.
- Для `STORE` второй адрес чтения — `rd` (источник данных), для остальных — `rs2`.
- `MUX B` выбирает `rs2_data` или `imm16` на вход `B` АЛУ.
- `ALU` формирует результат и флаги `Z/C`.
- `MUX WB` выбирает между `alu_y` и `data_rdata`.
- `addr_reg` фиксирует адрес для `LOAD`/`STORE`.
- Для переходов `PC` загружается `IR[9:0]`.

## 6. Память

| Область | Адреса | Доступ |
|---|---|---|
| `Data_RAM` | `0x0000–0x03FF` | чтение/запись |
| `Video_Memory` | `0x1000–0x1007` | чтение/запись |
| `MMIO` | `0xF000–0xF0FF` | внешняя шина |
| `Instruction_ROM` | отдельное пространство | только чтение |

`Data_RAM`, `Instruction_ROM` и `Video_Memory` имеют синхронное чтение. Поэтому для `LOAD` и выборки команды в FSM добавлены такты ожидания.

Декодер адреса формирует:

- `sel_ram`;
- `sel_matrix`;
- `sel_mmio`.

MUX чтения выбирает `ram_rdata`, `video_rdata`, `mmio_rdata` или `0`; результат — `data_rdata`.

## 7. MMIO

Сейчас в RTL реализованы шина и декодер MMIO. Внешние устройства ещё не подключены. Планируемое распределение:

| Адрес | Устройство |
|---|---|
| `0xF000` | кнопки Pong, 4 бита |
| `0xF001` | счёт Pong |
| `0xF010` | кнопки BCD `+1`/`−1` |
| `0xF011` | индикатор BCD |
| `0xF020–0xF02F` | резерв |

## 8. Тактирование и сброс

- Один общий `clk`.
- Все элементы состояния синхронные.
- Сброс синхронный, активный высокий.
- `PC`, `IR`, `addr_reg`, регистровый файл, флаги и видеопамять сбрасываются.
- `Data_RAM` и `Instruction_ROM` сбросом не очищаются; они инициализируются нулями и файлами `$readmemh`.

## 9. Ограничения текущей версии

- Нет конвейера и кэша.
- Нет стека, `CALL`/`RET`, прерываний, DMA и таймера.
- Нет умножения, деления, сдвигов и плавающей точки.
- `COLLISION_CHK` (`0x1F`) зарезервирована, но не реализована.
- MMIO-устройства не подключены; есть только шина и декодер.
- `C` сохраняется, но в управлении переходами используется только `Z`.
