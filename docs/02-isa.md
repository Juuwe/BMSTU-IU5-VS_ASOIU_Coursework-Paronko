# 02. Система команд (ISA)

## 1. Общие параметры

| Параметр | Значение |
|---|---:|
| Данные | 16 бит |
| Команда | 32 бита |
| КОП | 5 бит |
| РОН | 8 × 16 бит, `R0 = 0` |
| `PC` | 10 бит |
| Адресация памяти | `imm(rs1)`: база + смещение |
| Переходы | абсолютный 10-битный адрес слова |
| Флаги | `Z`, `C` |
| Сброс | синхронный, активный высокий |

`R0` всегда читается как 0; запись в него игнорируется. Регистры `R1–R7` — обычные 16-битные РОН.

## 2. Форматы команд

### R-формат

```text
31      27 26   24 23   21 20   18 17                  0
+----------+-------+-------+-------+---------------------+
|  opcode  |  rd   |  rs1  |  rs2  |  резерв (0)         |
+----------+-------+-------+-------+---------------------+
```

### I-формат

```text
31      27 26   24 23   21 20                          0
+----------+-------+-------+-----------------------------+
|  opcode  |  rd   |  rs1  |         imm[20:0]           |
+----------+-------+-------+-----------------------------+
```

| Поле | Биты | Назначение |
|---|---|---|
| `opcode` | 31:27 | код операции |
| `rd` | 26:24 | приёмник; для `STORE` — источник данных |
| `rs1` | 23:21 | первый операнд / база адреса |
| `rs2` | 20:18 | второй операнд R-формата |
| `imm` | 20:0 | знаковое значение/смещение I-формата |

В R-формате биты 17:0 должны быть нулевыми. Для адреса данных используются младшие 16 бит `imm`, для адреса перехода — младшие 10 бит.

## 3. Регистры и флаги

| Регистр | Ширина | Назначение |
|---|---:|---|
| `R0` | 16 | константа 0 |
| `R1–R7` | 16 | РОН общего назначения |
| `PC` | 10 | адрес команды в `Instruction_ROM` |
| `IR` | 32 | текущая команда |
| `Z` | 1 | результат равен нулю |
| `C` | 1 | перенос; при вычитании — `1`, если `A ≥ B` |

`SP`, `CALL`, `RET`, прерывания и DMA не вводятся.

## 4. Набор команд

| Код | Мнемоника | Формат | Действие | Флаги |
|---:|---|---|---|---|
| `0x00` | `HALT` | — | остановка | — |
| `0x01` | `ADD rd, rs1, rs2` | R | `rd ← rs1 + rs2` | `Z,C` |
| `0x02` | `SUB rd, rs1, rs2` | R | `rd ← rs1 − rs2` | `Z,C` |
| `0x03` | `AND rd, rs1, rs2` | R | `rd ← rs1 & rs2` | `Z` |
| `0x04` | `OR rd, rs1, rs2` | R | `rd ← rs1 \| rs2` | `Z` |
| `0x05` | `XOR rd, rs1, rs2` | R | `rd ← rs1 ^ rs2` | `Z` |
| `0x06` | `NOT rd, rs1` | R | `rd ← ~rs1` | `Z` |
| `0x07` | `LOAD rd, imm(rs1)` | I | `rd ← память[rs1 + imm]` | — |
| `0x08` | `STORE rd, imm(rs1)` | I | `память[rs1 + imm] ← rd` | — |
| `0x09` | `JUMP target` | I | `PC ← target` | — |
| `0x0A` | `BEQ target` | I | если `Z = 1`, `PC ← target` | — |
| `0x0B` | `BNE target` | I | если `Z = 0`, `PC ← target` | — |
| `0x0C` | `CMP rs1, rs2` | R | флаги по `rs1 − rs2` | `Z,C` |
| `0x0D` | `ADDI rd, rs1, imm` | I | `rd ← rs1 + imm` | `Z,C` |
| `0x0E` | `SUBI rd, rs1, imm` | I | `rd ← rs1 − imm` | `Z,C` |
| `0x0F` | `ANDI rd, rs1, imm` | I | `rd ← rs1 & imm` | `Z` |
| `0x10` | `ORI rd, rs1, imm` | I | `rd ← rs1 \| imm` | `Z` |
| `0x11` | `XORI rd, rs1, imm` | I | `rd ← rs1 ^ imm` | `Z` |
| `0x12` | `CMPI rs1, imm` | I | флаги по `rs1 − imm` | `Z,C` |
| `0x13` | `NOP` | — | `PC ← PC + 1` | — |
| `0x14–0x1E` | резерв | — | — | — |
| `0x1F` | `COLLISION_CHK` | R | зарезервировано, не реализовано | — |

`BEQ`/`BNE` проверяют только `Z`. Для сравнения двух регистров используется `CMP rs1, rs2` + `BEQ target`/`BNE target`. Ассемблер может поддерживать псевдокоманду с двумя регистрами, раскрывая её в две инструкции.

## 5. Адресация

```text
LOAD  rd, imm(rs1)     ; rd <- память[rs1 + imm]
STORE rd, imm(rs1)     ; память[rs1 + imm] <- rd
```

- `imm = 0` — косвенная адресация `[rs1]`.
- `rs1 = R0` — абсолютный адрес.
- Для массива база хранится в `rs1`, смещение задаёт индекс; переход к следующему элементу — через `ADDI` или изменение базы.

## 6. Переходы

- `JUMP`, `BEQ`, `BNE` используют **абсолютный 10-битный адрес слова** в `Instruction_ROM`.
- При ложном условии `PC` увеличивается на 1.
- Относительных переходов, переходов по регистру и задержек переходов нет.
- В ассемблере (следующий этап) метки будут подставляться в абсолютный адрес.

## 7. Флаги

- `Z = 1`, если результат операции равен нулю.
- `C`:
  - для `ADD` — перенос из старшего разряда;
  - для `SUB`/`CMP` — `1`, если `A ≥ B` (нет заёма).
- Логические команды обновляют только `Z`.
- `LOAD`, `STORE`, `JUMP`, `BEQ`, `BNE`, `NOP`, `HALT` флаги не меняют.
- `N` и `V` не вводятся.

## 8. Сброс

- Синхронный, активный высокий.
- `PC = 0`, `R1–R7 = 0`, `Z = C = 0`.
- `IR` и `addr_reg` очищаются.
- Видеопамять очищается.
- `Instruction_ROM` инициализируется нулями и файлом `$readmemh`; `Data_RAM` — аналогично, но сбросом не очищается.

## 9. Примеры

```text
ADD   R1, R2, R3        ; R1 = R2 + R3
LOAD  R1, 0(R0)         ; R1 = память[0]
STORE R1, 4(R2)         ; память[R2 + 4] = R1
JUMP  0x010             ; PC = 0x010
CMP   R1, R2
BEQ   0x020             ; если R1 == R2, PC = 0x020
```
