# 05. Программы и машинный код

## 1. Формат программ

`Instruction_ROM` имеет размер 1024 × 32 и инициализируется файлом `$readmemh`. Каждая строка `.hex` — одно 32-битное слово команды:

```text
69000000
3a0000ff
3b200000
...
```

`Data_RAM` инициализируется отдельным файлом `$readmemh`; каждая строка — одно 16-битное слово данных.

## 2. Файлы

| Файл | Назначение |
|---|---|
| `programs/task3.hex` | программа №23 в машинных кодах |
| `programs/task3.ram.hex` | исходный массив и длина для `tb_task3` |
| `programs/task3.md` | листинг task3: адрес, мнемоника, код |
| `programs/isa_smoke.hex` | ручная программа проверки ISA |
| `programs/isa_smoke.md` | описание проверок и ожидаемых ячеек RAM |

Это **ручной машинный код**, не результат ассемблера. Ассемблер — следующий этап.

## 3. Программа №23

Задание: удалить подряд идущие дубликаты в массиве 16-битных слов, заменив повторные вхождения нулями. Результат остаётся в том же массиве (in-place).

### Контракт

| Параметр | Значение |
|---|---|
| Адрес массива | `0x0000` |
| Адрес длины | `0x00FF` |
| Длина | переменная; в тесте 10 |
| Режим | in-place |
| Исходные данные | `1,1,2,2,2,5,5,7,8,9` |
| Ожидаемый результат | `1,0,2,0,0,5,0,7,8,9` |
| Завершение | `HALT` |

### Алгоритм

1. Загрузить длину из `0x00FF`.
2. Прочитать первый элемент и запомнить его как «предыдущий».
3. Для индекса от 1 до длины−1:
   - прочитать текущий элемент;
   - сравнить с предыдущим;
   - если равны — записать 0 в текущую ячейку;
   - иначе запомнить текущий как предыдущий;
   - увеличить индекс.
4. Остановиться.

### Регистры

| Регистр | Назначение |
|---|---|
| `R1` | база массива = 0 |
| `R2` | длина массива |
| `R3` | предыдущий элемент |
| `R4` | индекс |
| `R5` | адрес текущего элемента |
| `R6` | текущий элемент |

Полный листинг с адресами и hex-кодами — в [`programs/task3.md`](../programs/task3.md).

## 4. `isa_smoke`

`isa_smoke.hex` — ручная программа, которая проверяет:

- арифметику и логику;
- immediate-команды;
- `CMP`/`CMPI`;
- `LOAD`/`STORE` с `imm(rs1)`;
- `JUMP`/`BEQ`/`BNE`;
- `NOP`, `HALT`;
- запись в видеопамять `0x1000`.

Ожидаемые результаты по ячейкам RAM и `matrix_rows` перечислены в [`programs/isa_smoke.md`](../programs/isa_smoke.md). Программа запускается тестом `tb_soc`.

## 5. Запуск

```bash
make test
```

Тесты `tb_soc` и `tb_task3` загружают соответствующие `.hex`-файлы. VCD-файлы появятся в `sim_build/`.

## 6. Планы развития

Следующий этап — собственный ассемблер:

- метки и комментарии;
- директивы `.data`, `.word`, `.equ`, `.org`;
- псевдоинструкции `LI`, `MOV`;
- генерация `.hex`/`.bin`, совместимых с `$readmemh`/`$readmemb`;
- cross-verification с ручным машинным кодом.

Затем — MMIO-устройства, BCD/Pong и интерактивный мост.
