# `isa_smoke.hex` — ручной тест ISA

Это **не** результат ассемблера: машинный код написан вручную для проверки первой спеки. Ассемблер появится на следующем этапе.

Программа проверяет:

- `ADD/SUB/AND/OR/XOR/NOT`;
- `ADDI/SUBI/ANDI/ORI/XORI`;
- `CMP/CMPI`;
- `LOAD/STORE` с `imm(rs1)`, включая косвенную адресацию;
- `JUMP/BEQ/BNE`, истинные и ложные условия;
- `NOP`, `HALT`;
- запись в LED-матрицу `0x1000`.

## Ожидаемые результаты в RAM

| Адрес | Значение | Что проверяет |
|---:|---:|---|
| `0x100` | `0x0008` | `ADD` |
| `0x101` | `0x0002` | `SUB` |
| `0x102` | `0x0001` | `AND` |
| `0x103` | `0x0007` | `OR` |
| `0x104` | `0x0006` | `XOR` |
| `0x105` | `0xFFFC` | `NOT` |
| `0x106` | `0x000D` | `ADDI` |
| `0x107` | `0x000A` | `SUBI` |
| `0x108` | `0x000A` | `ANDI` |
| `0x109` | `0x0030` | `ORI` |
| `0x10A` | `0x003F` | `XORI` |
| `0x120` | `0x003F` | `CMPI` + `BEQ` true |
| `0x121` | `0x003F` | `CMPI` + `BNE` true |
| `0x122` | `0x600D` | `BEQ` false |
| `0x123` | `0x1234` | `JUMP` |
| `0x124` | `0x7777` | `CMP` + `BNE` false |
| `0x125` | `0x8888` | `CMP` + `BEQ` false |
| `0x200` | `0x0006` | `STORE [R3]` |
| `0x201` | `0x0006` | `LOAD [R3]` + `STORE [R5]` |
| `0x202` | `0x0006` | `LOAD` из LED-матрицы |

`matrix_rows[15:0]` после выполнения: `0x0006`.

## Как запускать

```bash
make test
```

Тест `tb_soc` загружает `programs/isa_smoke.hex` в `Instruction_ROM`, ждёт `halt` и проверяет перечисленные ячейки RAM и строку матрицы. Волновая диаграмма — `sim_build/tb_soc.vcd`.
