# `task3.hex` — программа №23

Задание: удалить подряд идущие дубликаты в массиве 16-битных слов, заменив повторные вхождения нулями. Результат — in-place.

## Контракт

| Параметр | Значение |
|---|---|
| Массив | `0x0000` |
| Длина | слово по адресу `0x00FF` |
| Длина в тесте | 10 |
| Исходные данные | `1,1,2,2,2,5,5,7,8,9` |
| Ожидаемый результат | `1,0,2,0,0,5,0,7,8,9` |

## Листинг

| Адрес | Мнемоника | Код |
|---:|---|---:|
| 0 | `ADDI R1, R0, 0` | `0x69000000` |
| 1 | `LOAD R2, 0x00FF(R0)` | `0x3A0000FF` |
| 2 | `LOAD R3, 0(R1)` | `0x3B200000` |
| 3 | `ADDI R4, R0, 1` | `0x6C000001` |
| 4 | `CMP R4, R2` | `0x60880000` |
| 5 | `BEQ done` | `0x5000000F` |
| 6 | `ADD R5, R1, R4` | `0x0D300000` |
| 7 | `LOAD R6, 0(R5)` | `0x3EA00000` |
| 8 | `CMP R6, R3` | `0x60CC0000` |
| 9 | `BEQ duplicate` | `0x5000000C` |
| 10 | `ADD R3, R6, R0` | `0x0BC00000` |
| 11 | `JUMP next` | `0x4800000D` |
| 12 | `STORE R0, 0(R5)` | `0x40A00000` |
| 13 | `ADDI R4, R4, 1` | `0x6C800001` |
| 14 | `JUMP loop` | `0x48000004` |
| 15 | `HALT` | `0x00000000` |

## Регистры

| Регистр | Назначение |
|---|---|
| `R1` | база массива = 0 |
| `R2` | длина массива |
| `R3` | предыдущий элемент |
| `R4` | индекс |
| `R5` | адрес текущего элемента |
| `R6` | текущий элемент |
