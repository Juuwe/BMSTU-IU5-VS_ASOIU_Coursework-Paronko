# 16-битное процессорное ядро и SoC на Verilog

Собственное процессорное ядро с ISA, гарвардской архитектурой, MMIO-декодером и программой обработки массива в машинных кодах.

## Вариант

Группа **ИУ5-51Б**, вариант **11**, 2026.

| Оценка | Задание |
|---|---|
| «3» | №23 — удаление подряд идущих дубликатов, данные в RAM |
| «4» | №18 — BCD Counter 00–99 |
| «5» | №1 — Pong (1D), LED-матрица 8×8, `COLLISION_CHK` |

## Архитектура

- гарвардская: память команд отдельно от памяти данных;
- данные 16 бит, команда 32 бита;
- 8 регистров по 16 бит, `R0 = 0`;
- автомат Мура в `Control_Unit`;
- синхронное чтение памяти;

Карта данных:

| Область | Адреса |
|---|---|
| ОЗУ данных | `0x0000–0x03FF` |
| Видеопамять 8×8 | `0x1000–0x1007` |
| MMIO | `0xF000–0xF0FF` |

## Реализовано

RTL:

- `rtl/ALU.v` — 16-битное АЛУ, `Z/C`;
- `rtl/Register_File.v` — 8×16;
- `rtl/Program_Counter.v` — 10-битный PC;
- `rtl/Instruction_ROM.v` — 1024×32;
- `rtl/Data_RAM.v` — 1024×16;
- `rtl/Video_Memory.v` — 8×16;
- `rtl/Memory_Top.v` — RAM/Video/MMIO;
- `rtl/Control_Unit.v` — FSM;
- `rtl/CPU_Core.v` — тракт и управление;
- `rtl/soc_top.v` — верхний уровень.

Программы:

- `programs/isa_smoke.hex` — проверка ISA;
- `programs/task3.hex` — задание №23 в машинных кодах;
- `programs/task3.ram.hex` — исходный массив и длина.

Тесты:

- `tb/tb_alu.v`;
- `tb/tb_register_file.v`;
- `tb/tb_memory.v`;
- `tb/tb_soc.v`;
- `tb/tb_task3.v`.
