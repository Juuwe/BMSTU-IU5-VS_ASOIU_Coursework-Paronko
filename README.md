# Курсовая работа

## 1. Тема и декомпозиция на технические требования

**Тема:** разработка 16-битного процессорного ядра с собственной ISA, гарвардской памятью, MMIO-декодером и SoC на Verilog.

**Технические требования:**

1. Гарвардская архитектура: память команд `1024×32` отделена от памяти данных `1024×16`; `PC` — 10 бит.
2. Данные — 16 бит, команда — 32 бита, КОП — 5 бит; 8 регистров общего назначения по 16 бит, `R0 = 0`.
3. ISA: `ADD`, `SUB`, `AND`, `OR`, `XOR`, `NOT`, `LOAD`, `STORE`, `JUMP`, `BEQ`, `BNE`, `CMP`, `CMPI`, `ADDI`, `SUBI`, `ANDI`, `ORI`, `XORI`, `HALT`, `NOP`; адресация `imm(rs1)`, абсолютные переходы, флаги `Z/C`.
4. Карта данных: RAM `0x0000–0x03FF`, видеопамять `0x1000–0x1007`, MMIO `0xF000–0xF0FF`.
5. `Control_Unit` — Автомат Мура; многотактное выполнение без конвейера и кэша; синхронный сброс.
6. Верхний уровень `soc_top`: CPU, память, MMIO-декодер и внешние устройства.
7. Программы варианта: №23 — удаление подряд идущих дубликатов; BCD Counter 00–99; Pong 1D с командой `COLLISION_CHK`.
8. Верификация: модульные и интеграционные тестбенчи, `make test`, `make lint`, временные диаграммы VCD/GTKWave.
9. Синтез RTL и оформление отчёта.

## 3. Главные технические проблемы

**Уже решена:** сборка и верификация процессорного ядра на Verilog и выполнение программы варианта в машинных кодах — обязательная часть на оценку «3»: модули `ALU`, `Register_File`, `Control_Unit`, `Program_Counter`, `Memory_Top`, `CPU_Core`, `soc_top`, автоматические тестбенчи и `tb_task3`.

**Предстоит:** переход от ручного машинного кода к собственному toolchain — разработка ассемблера с метками, директивами `.data`/`.word` и генерацией `.hex` для `$readmemh` (следующий этап, оценка «4»).
